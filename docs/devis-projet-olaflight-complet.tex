\section{Objet}
Le présent devis couvre la \textbf{réalisation, l'intégration et la mise en production} d'une plateforme digitale complète «\,OLA Flight\,» : site vitrine premium, \textbf{agent conversationnel IA} avec exécution d'actions métier (création de leads, devis, PDF, recherche tarifs), \textbf{CRM interne} avec rôles (admin / closer), notifications, résumés de conversation, et \textbf{préparation au déploiement} (Docker, documentation, option cloud serverless).

\section{Contexte et objectifs métier}
\begin{itemize}[leftmargin=*]
  \item Offrir une expérience \textbf{concierge premium} (style airline / luxe) sur le web.
  \item Permettre à l'agent IA de \textbf{qualifier} le client, de \textbf{proposer plusieurs options} de voyage (Express / Confort / Premium), éventuellement \textbf{hôtels} et \textbf{chauffeur privé}, et de \textbf{générer un devis PDF} exploitable commercialement.
  \item Assurer un \textbf{suivi CRM} équivalent à un opérateur humain : pipeline, dispatching closer, audit des actions agent, résumés pour les commerciaux.
  \item Conserver une \textbf{piste d'audit} et un périmètre de données \textbf{conforme aux rôles} (admin vs closer).
\end{itemize}

\section{Périmètre fonctionnel détaillé}

\subsection{Front-office (site public)}
\begin{itemize}[leftmargin=*]
  \item Landing page premium (identité typographique luxe, animations motion design type Apple/Linear via GSAP).
  \item \textbf{Call-to-action} vers le chatbot comme canal principal (remplacement du parcours WhatsApp sur la home).
  \item Chatbot web persisté (conversation + \texttt{conversation\_id}), fichier affichage chargement, réponses rapides post-devis (accepter / négocier / refuser).
  \item Internationalisation FR / EN sur les éléments clés (hero, navigation, chat).
\end{itemize}

\subsection{Agent IA (Anthropic / outillage)}
\begin{itemize}[leftmargin=*]
  \item Orchestration \textbf{tool-calling} : recherche vols (scraping Booking / Google Flights en secours), \texttt{upsert\_lead}, \texttt{create\_devis\_from\_offer}.
  \item Qualification structurée : identité, route, dates, classe, type de client (\textbf{particulier / pro / corporate}), hôtel (optionnel), \textbf{chauffeur (obligatoire} à la question).
  \item Devis multi-options (jusqu'à 3 paliers) avec règles commerciales (comparatif marché masqué pour les particuliers).
  \item Journalisation des actions dans \texttt{agent\_actions} (audit).
  \item Résumé conversation IA pour la fiche lead (bullets actionnables).
\end{itemize}

\subsection{Back-office (CRM / admin)}
\begin{itemize}[leftmargin=*]
  \item Authentification JWT (cookie), rôles admin / closer, isolation des données closer.
  \item \textbf{Pipeline Kanban} : recherche, filtres, tri, zoom par colonne de statut.
  \item Fiche lead : statut, réassignation closer (admin), résumé IA, historique agent, liste des devis.
  \item \textbf{Édition manuelle} d'un devis existant + régénération PDF.
  \item Notifications in-app (cloche) sur événements métier (nouveau devis, gagné, négociation, etc.).
  \item Page admin scraping manuel (Google Flights / Booking selon configuration).
\end{itemize}

\subsection{Devis PDF et règles financières}
\begin{itemize}[leftmargin=*]
  \item Génération PDF via Playwright (mise en page multi-options, extras hôtels / chauffeur).
  \item Calcul marge / commissions (closer, apporteur) centralisé ; masquage des champs sensibles selon rôle.
  \item Support schéma \textbf{multi-options} et colonnes extras (migrations base).
\end{itemize}

\subsection{Données et persistance}
\begin{itemize}[leftmargin=*]
  \item Support \textbf{SQLite} (développement / démo locale) et \textbf{Supabase} (PostgreSQL) pour production.
  \item Migrations versionnées (notifications, options devis, champs lead extras, conversations, users, etc.).
  \item Conversations web conservées de façon étendue (plafond technique élevé pour les particuliers).
\end{itemize}

\subsection{Scraping et recherche tarifaire}
\begin{itemize}[leftmargin=*]
  \item Automatisation Playwright (anti-détection, secours multi-sources).
  \item Exposition opérateur via route admin pour tests et démos.
\end{itemize}

\subsection{Déploiement et documentation}
\begin{itemize}[leftmargin=*]
  \item \textbf{Dockerfile} image Playwright pour hébergement type Railway / Render / Fly.
  \item Option \textbf{Vercel} (serverless) documentée avec limites PDF/scraper.
  \item README : installation développeur, variables d'environnement, ordre des migrations Supabase, dépannage.
\end{itemize}
